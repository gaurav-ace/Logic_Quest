# Changelog

## Phase 0, Foundations (done 2026-10-19)

- 0.1 Tooling: TypeScript 6.0.3, Vite 8.3.4, Vitest 5.0.5, ESLint 10.13.0 with typescript-eslint 8.71.2. All pinned exactly. Scripts: `dev`, `build`, `typecheck`, `lint`, `test`, `check`.
- 0.2 Lesson schema (`src/lesson/schema.ts`) and validator (`src/lesson/validate.ts`). The validator reports every problem with its path, rejects unknown fields, and checks that node references, edges, step hops and quiz answers are consistent. First lesson data: `lessons/hello.json` (sourced from MDN).
- 0.3 Hello lesson renders from data (`index.html`, `src/render/lesson.ts`, `src/styles.css`, `src/engine/packet.ts`): goal, SVG diagram with a moving packet, step captions, Back/Next, and a quiz that explains every option and offers a replay after a wrong answer. Mobile first, system fonts, 48 px tap targets, safe areas, light/dark, reduced motion. Removed the 0.1 placeholder smoke test.
- 0.4 Installable PWA: `public/manifest.webmanifest`, icons (SVG plus 192/512/maskable PNGs drawn by `scripts/make_icons.py`, stdlib only), and a hand-written service worker (`src/pwa/sw.js`). A small Vite plugin writes `dist/sw.js` with the exact list of built files, and a content-based cache version (`src/pwa/precache.ts`, tested), so the whole app is cached on first visit and works offline. Registered only in production builds.
- 0.5 CI and deploy: `.github/workflows/ci.yml` runs `npm ci`, lint, typecheck, tests and build on every push and pull request, and publishes `main` to GitHub Pages. README rewritten with dev commands and layout; `docs/IDEAS.md` started.

## Phase 1, Animation engine (done 2026-10-19)

- 1.1 Step player (`src/engine/player.ts`): pure state machine for next/back/go-to, play/pause, 0.5x/1x/2x speed and auto-advance after a reading time based on caption length. A long frame never skips a step; reduced motion shows the packet at its destination but keeps reading time. 31 unit tests.
- 1.2 Renderer runs on the player. New controls: step dots (48 px tap targets), speed, Back / Play-Pause-Replay / Next. Auto-play pauses when the tab is hidden, and frames stop when nothing moves. Renderer split into `dom`, `diagram`, `controls`, `quiz` and `lesson` modules. Headless Chrome check script added as `scripts/browser-check.mjs`. Source links are now full-size tap targets.
- 1.3 Three lessons as data: `lessons/load-balancer.json`, `cache.json`, `agent-loop.json`. Each has 5 steps, 2 quiz questions with every option explained, sources (NGINX docs, Azure Cache-Aside pattern, Anthropic "Building effective agents", the ReAct paper) and a "what this simplifies" note. Schema: optional node `width`; the validator now rejects unknown node fields and boxes outside the diagram. `src/lesson/catalog.ts` loads and validates every lesson, and a test fails if a lesson file is not listed.
- 1.4 Home screen listing the lessons, and hash routes (`#/lesson/<id>`, `src/router.ts`, tested). The Android back button returns to the list; pressing back during a quiz opens a "Leave the quiz?" sheet with Stay as the main choice; deep links get a home entry underneath so back never closes the app; unknown links fall back to the list. "Take the quiz" is disabled while the quiz is open. Browser checks extended to navigation, the guard and all four lessons (69 UI + 7 PWA checks).
- CI: the Pages artifact is named per run attempt, so re-running a workflow no longer fails with "Multiple artifacts named github-pages".

## Phase 2, Rewards and progress (in progress)

- 2.1 Reward engine (`src/rewards/`): progress is an event log, and XP, level, streak, coins and badges are computed from it by pure functions. XP comes only from correct answers (10 first try, 5 after a retry, 10 for first completing a lesson; never negative, each question scored once). Streak coins: +5 per goal day; one missed day uses a buffer (−15), a second breaks the streak (−25); never below 0. 18 config-driven badges. All numbers in `src/rewards/rewards.config.json`, validated at load. Lessons now have `track` and `level`. 56 new tests, plus mutation checks on anti-farming, the coin floor and "today is never a miss".
- 2.2 Progress storage (`src/progress/store.ts`): versioned save in localStorage; every write re-reads and merges by event id, so two open tabs never overwrite each other; an unreadable save is copied to a backup key and reported, never silently dropped (and never overwritten if the copy fails); full or blocked storage keeps progress in memory with a notice. Export to JSON and import with a preview; importing merges, so the same file twice adds nothing. 19 tests.
